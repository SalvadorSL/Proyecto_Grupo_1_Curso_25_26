# Proyecto_Grupo_1_Curso_25_26
Sistema de Gestión de Proyectos

## Planify

**Planify** es una herramienta integral de gestión de proyectos basada en metodologías ágiles. Está diseñada para ofrecer el equilibrio perfecto entre una interfaz visual intuitiva (estilo Kanban) y el control avanzado necesario para escalar desde tareas individuales hasta flujos de trabajo complejos en grandes equipos.

### Sobre el proyecto

Planify nace tras un análisis detallado de las herramientas líderes del mercado, con el objetivo de resolver sus principales carencias. Buscamos ofrecer una plataforma donde la facilidad de uso no sacrifique la potencia, permitiendo a los equipos colaborar, organizar y transformar sus ideas en resultados sin fricciones. 

#### Funcionalidades Principales y Ventajas Competitivas

* **Equilibrio entre Potencia y Usabilidad:** Interfaz clara y una curva de aprendizaje rápida, capaz de gestionar múltiples proyectos y equipos sin volverse caótico.
* **Notificaciones y Recordatorios Automatizados:** Sistema inteligente de alertas para tareas pendientes y fechas de vencimiento, evitando los olvidos frecuentes de otras plataformas.
* **Visualización Cronológica Nativa:** Más allá del clásico tablero, Planify integra líneas de tiempo y Diagramas de Gantt para ofrecer una perspectiva temporal real y clara del progreso del proyecto.
* **Amplia Biblioteca de Plantillas:** Catálogo de estructuras predefinidas para distintos sectores (desarrollo de software, mundo académico, marketing), reduciendo drásticamente el tiempo de configuración inicial.
